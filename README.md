
📊 Excel Sales Performance Analysis

📌 Project Overview

This project focuses on analyzing sales performance using Microsoft Excel to understand sales trends, profitability, regional performance, and inventory status. The project includes an interactive dashboard and multiple analytical reports to support data-driven business decisions.

The objective is to transform sales data into meaningful insights that help businesses monitor performance, identify trends, and improve decision-making.

🎯 Project Objectives

- Analyze overall sales performance and product categories.
- Evaluate profit, profit margins, and average net amount by product type.
- Track monthly sales targets across different regions.
- Understand order status across sales channels.
- Analyze salesperson performance and SKU stock levels.
- Present key business insights through visualizations and an Excel dashboard.

🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning and Data Preparation
- Excel Formulas and Functions
- Data Analysis and Visualization
- Dashboard Creation
- Business Intelligence and Reporting
